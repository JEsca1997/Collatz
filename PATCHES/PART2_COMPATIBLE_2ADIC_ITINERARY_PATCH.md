# Part 2 Patch: Compatible 2-adic Itineraries

**Scope.** This patch replaces the false jump assertion in Lemma 6.1 / Lemma 19.1(b):
\[
v_2(a_{n+1}-a_n)=M_n.
\]
The prefix-cocycle identity remains valid. The no-divergence theorem does **not** follow from this patch alone.

---

## 1. Block setting

Let
\[
2^{m_i}y_i=3^{s_i}y_{i-1}+D_i,
\qquad m_i\ge1,\quad s_i\ge0,\quad D_i\ \text{odd},
\]
and define
\[
M_n=\sum_{i=1}^n m_i,
\qquad
S_n=\sum_{i=1}^n s_i.
\]

Define recursively
\[
C_1=D_1,
\qquad
C_{n+1}=3^{s_{n+1}}C_n+2^{M_n}D_{n+1}.
\]
Then every \(C_n\) is odd and the exact prefix cocycle is
\[
\boxed{
2^{M_n}y_n=3^{S_n}y_0+C_n.
}
\]

This is the valid content of the original Lemma 6.1(a).

---

## 2. Correct residue theorem

For each \(n\), define the residue class
\[
r_n\in\mathbb Z/2^{M_n}\mathbb Z
\]
by
\[
r_n\equiv-3^{-S_n}C_n\pmod{2^{M_n}}.
\]

### Theorem (compatibility)
The classes are compatible under reduction:
\[
\boxed{
r_{n+1}\equiv r_n\pmod{2^{M_n}}.
}
\]

### Proof
Using the recurrence for \(C_{n+1}\),
\[
\begin{aligned}
-3^{-S_{n+1}}C_{n+1}
&=-3^{-S_n}C_n-2^{M_n}3^{-S_{n+1}}D_{n+1}.
\end{aligned}
\]
The second term is divisible by \(2^{M_n}\) in \(\mathbb Z_2\). Reducing modulo \(2^{M_n}\) gives the claim. \(\square\)

---

## 3. What canonical representatives actually satisfy

Let \(a_n\in[0,2^{M_n})\) be the canonical integer representative of \(r_n\). Compatibility implies only
\[
\boxed{
a_{n+1}=a_n+2^{M_n}b_n
}
\]
for a uniquely determined integer
\[
0\le b_n<2^{m_{n+1}}.
\]

Nothing in the oddness of \(D_{n+1}\) forces \(b_n\) to be odd.

The invalid step in the prior proof was replacing the 2-adic number
\[
-3^{-S_n}C_n
\]
by its canonical representative \(a_n\) modulo the stronger modulus \(2^{M_{n+1}}\). The equality is available only modulo \(2^{M_n}\), leaving the lift digit \(b_n\) undetermined.

Therefore neither
\[
a_{n+1}\ne a_n
\]
nor
\[
v_2(a_{n+1}-a_n)=M_n
\]
follows in general.

---

## 4. Inverse-limit interpretation

The compatible system \((r_n)_n\) defines a unique 2-adic integer
\[
\boxed{
y_\infty\in\mathbb Z_2,
\qquad y_\infty\equiv r_n\pmod{2^{M_n}}\ \forall n.
}
\]

Thus an arbitrary infinite block itinerary naturally determines a 2-adic starting point. This is not a contradiction: compatible residue cylinders are exactly how \(\mathbb Z_2\) is constructed.

---

## 5. Correct realization criterion

Assume \(M_n\to\infty\). A positive integer \(y_0\in\mathbb N\) realizes the specified block itinerary only if
\[
y_0\equiv r_n\pmod{2^{M_n}}\quad\forall n.
\]
Equivalently, its canonical representatives eventually stabilize:
\[
\boxed{
a_n=y_0\quad\text{for all sufficiently large }n.}
\]

Conversely, eventual stabilization at a positive integer \(y_0\) gives all required prefix congruences. Hence:
\[
\boxed{
\text{integer realization}
\iff
\text{the compatible 2-adic point }y_\infty\text{ lies in }\mathbb N.
}
\]

This criterion is valid. The former proof failed only at the attempted universal proof that stabilization never occurs.

---

## 6. New honest closing target

To recover a no-divergence theorem from the block program, one must prove a genuinely global statement:
\[
\boxed{
\text{Every infinite block itinerary generated by a non-terminating positive Collatz orbit has }y_\infty\notin\mathbb N.
}
\]

Equivalently, one needs a theorem forcing infinitely many nonzero lift digits \(b_n\) in a way incompatible with eventual stabilization.

Possible routes must supply an additional invariant tied to the **actual return/exit block language**, for example:

1. a forbidden-pattern theorem for the sequence of lift digits \(b_n\);
2. a monotone archimedean quantity jointly constrained with the 2-adic cocycle;
3. a finite-state automaton obstruction showing no eventually constant compatible path is generated by the shell-return language;
4. a modular obstruction valid uniformly across all lifted block prefixes.

None of these is proved in this patch.

---

## 7. Consequence for manuscript status

The following Part 2 components remain as exact local arithmetic statements, subject to separate checking of their own hypotheses:

- shell decomposition;
- rigid staircase identities;
- return and exit affine-block formulas;
- prefix cocycle;
- compatible residue construction;
- integer-realization criterion.

The implication
\[
\text{infinite blocks}\Rightarrow\text{canonical residues never stabilize}
\]
is withdrawn.

Therefore the present Part 2 document should be retitled as a study of **2-adic block itineraries and realization constraints**, not as a proof of no divergent trajectories, until the global target in Section 6 is established.
