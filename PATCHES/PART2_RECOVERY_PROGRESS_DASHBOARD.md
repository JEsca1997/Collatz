## What is currently safe to retain

### R0 — false claim removed

The following implication is false in the generic affine class:
\[
v_2(a_{n+1}-a_n)=M_n.
\]

A compatible residue system may stabilize. The fixed-point block example
\[
2\cdot1=3\cdot1-1
\]
shows that odd constants alone do not prevent it.

### R2 — exact compatible itinerary theorem

For a block sequence
\[
2^{m_i}y_i=3^{s_i}y_{i-1}+D_i,
\qquad m_i\ge1,
\quad D_i\ \text{odd},
\]
define
\[
M_n=\sum_{i\le n}m_i,
\qquad
S_n=\sum_{i\le n}s_i,
\]
and recursively define \(C_n\) so that
\[
2^{M_n}y_n=3^{S_n}y_0+C_n.
\]

Then
\[
r_n\equiv-3^{-S_n}C_n\pmod{2^{M_n}}
\]
forms a compatible inverse system:
\[
r_{n+1}\equiv r_n\pmod{2^{M_n}}.
\]

Thus every formal itinerary determines a 2-adic point
\[
y_\infty\in\mathbb Z_2.
\]

This is local arithmetic, not a no-divergence theorem.

## The new load-bearing theorem

The exact global target is:

\[
\boxed{
\begin{minipage}{0.86\linewidth}
For every infinite return/exit block itinerary that is actually generated by a positive Collatz orbit and does not reach \(1\), the associated compatible 2-adic point \(y_\infty\) is not a positive integer.
\end{minipage}
}
\]

Equivalently, write canonical lifts as
\[
a_{n+1}=a_n+2^{M_n}b_n,
\qquad 0\le b_n<2^{m_{n+1}}.
\]

A positive integer realization requires eventual stabilization:
\[
a_n=y_0\quad\text{for all sufficiently large }n.
\]

Therefore a sufficient new theorem is:
\[
\boxed{
\text{Every admissible nonterminating itinerary has infinitely many nonzero lift digits }b_n.
}
\]

The crucial qualifier is **admissible actual Collatz itinerary**. The theorem is false for arbitrary odd-constant affine blocks.

## Candidate recovery approaches

### A. Finite-state lift obstruction

**Goal.** Derive the exact transition law for \(b_n\) from the return/exit block type, its shell data, and a bounded amount of residue state.

Target form:
\[
(\text{state}_n,\text{block}_n)
\mapsto
(\text{state}_{n+1},b_n).
\]

Then prove no infinite path corresponding to a positive divergent orbit can enter an eventually-zero \(b_n\) tail.

**Immediate deliverable:** an exact automaton specification, not a heuristic simulation.

**Current status:** [█░░░░░░░░░] 10%.

### B. Mixed archimedean / 2-adic obstruction

**Goal.** Couple the exact 2-adic compatible residue with a monotone real-valued quantity from the actual return map.

A valid theorem would show that eventual stabilization forces an impossible real growth or return condition.

**Required discipline:** every inequality must track the real block multiplier
\[
3^{s_i}/2^{m_i}
\]
and the additive constant exactly. Average drift alone is insufficient.

**Current status:** [░░░░░░░░░░] 0%.

### C. Uniform modular obstruction

**Goal.** Find a modulus \(q\) or increasing compatible family of moduli such that every admissible infinite block word violates a necessary integer-realization congruence.

**Warning:** a modulus that excludes most paths but leaves a possible exceptional path is not a closure theorem.

**Current status:** [░░░░░░░░░░] 0%.

### D. Certified bounded-language computation

**Goal.** Prove a finite reduction theorem, then exhaust the finite residue automaton with exact arithmetic.

**Required order:** prove the finite bound first; computation cannot establish the absence of all unbounded itineraries by sampling.

**Current status:** [░░░░░░░░░░] 0%.

## Immediate sprint plan

### Sprint 1 — derive the actual lift digit

For each named block formula in Part 2:

1. write its exact affine data \((m,s,D)\);
2. compose one block after another;
3. compute \(C_{n+1}\) modulo \(2^{M_{n+1}+1}\), not merely modulo \(2^{M_n}\);
4. derive \(b_n\) explicitly;
5. test whether \(b_n=0\) forces a recognizable shell or residue condition.

**Success condition:** a theorem of the form
\[
b_n=0\iff \mathcal C(\text{finite state}_n).
\]

### Sprint 2 — build the admissible-language automaton

State must retain precisely the residues needed to determine:

- which return/exit block is legal;
- the next shell;
- the next lift digit;
- whether the block can belong to a positive orbit.

**Success condition:** a finite exact transition graph with no omitted infinite-state dependence.

### Sprint 3 — prove or disprove eventual-zero tails

Search for cycles or terminal strongly connected components in the automaton with
\[
b_n=0
\]
eventually.

- If such a component exists and is integer-realizable, this recovery route fails.
- If none exists, prove the exclusion symbolically and use it as R5.

1. prefix cocycle;
